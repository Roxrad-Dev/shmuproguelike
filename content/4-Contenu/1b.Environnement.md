# Block
### Identification
Nom: Block
Points de vie: 0
### Description
Le block est un élément cubique bloquant le joueur, les [[1a.Ennemis|ennemis]] et les attaques. Il n'est pas possible de le détruire et permet de délimiter des espaces, prodiguer des couvertures ou des obstacles.

# Block-\[k]
### Identification
Nom: Block-\[k]
Points de vie: 30

### Description
Le block-k est une variante destructible du block, il se comporte de la même manière que le block standard mais a la particularité de pouvoir être détruit par les attaques du joueur.

# Block-Burn
### Identification
Nom: Block-Burn
Points de vie: 0

### Description
Le block-burn est une variante destructible du block, il se comporte de la même manière que le block standard mais a la particularité d'infliger des dégâts au joueur quand il entre en collision avec. (Même lors de l'utilisation des [[1f.Booster]] ).

# Block-\[k]Burn
### Identification
Nom: Block-\[k]Burn
Points de vie: 50

### Description
Le Block-\[k]Burn est une variante destructible du Block-\[k]Burn, il se comporte de la même manière que le Block-\[k]Burn mais a la particularité  de pouvoir être détruit par les attaques du joueur.

# Tile Spikes
### Identification
Nom: Tile spikes
Points de vie: 0

### Description
La tile spikes est un élément semblable au Block-Burn infligeant des dégâts de contact au joueur quand il passe dessus. Cependant, cet élément n'est pas bloquant et il est possible au joueur, [[1a.Ennemis|ennemis]] et projectiles de le traverser. L'utilisation des [[1f.Booster]] empêche le joueur de prendre des dégâts des tiles spikes.


# Vide
### Identification
Nom: Vide
Points de vie: 0

### Description
Le vide sert d'obstacle au joueur et [[1a.Ennemis|ennemis]] mais pas aux projectiles. Il est impossible de passer au dessus ou d'y tomber. Il, entre autre, servir à délimiter des [[2.Niveaux|niveaux]] ou placer des [[1a.Ennemis|ennemis]] hors d'atteinte obligeant le joueur à utiliser ses [[1e.Tir]]s et non ses [[1f.Booster]]s pour les atteindre.
